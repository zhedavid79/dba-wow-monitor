- **Kabinet (PERMANENT FOUNDATION):** hard gates: mATX compatible, GPU/cooler clearance compatible. Jonsbo Z20 is the intended final enclosure, so an exact Z20 receives value only because it avoids a later case replacement.
- **CPU-køler (LONG-LIVED FOUNDATION):** hard gates: AM5 compatible, <=163 mm for Z20. Adequate air cooling wins; expensive cooling receives no gaming-performance premium unless it buys a concrete noise/thermal benefit.
- **RAM (SEMI-DURABLE):** hard gates: desktop DDR5, non-RDIMM/SO-DIMM, >=16GB. 32GB DDR5-6000 is the long-term target, but a 16GB bridge is valid only when the avoided spend clearly exceeds its future-upgrade penalty.
- **CPU (REPLACEABLE PERFORMANCE):** hard gates: compatible with chosen AM5 foundation, function verified if used. Rank on WoW CPU score and price. Do not pay large future-proofing premiums when the socket itself preserves the X3D upgrade path.
- **Grafikkort (REPLACEABLE PERFORMANCE):** hard gates: function verified if used, Z20 fit must not be known-NO. Rank on target-resolution performance, price and a modest VRAM/longevity allowance. Performance hardware must earn its premium now.
- **SSD/lager (CONVENIENCE / EASY UPGRADE):** hard gates: NVMe, >=500GB. Capacity above adequacy gets only a modest value because storage is easy to add and gives little WoW FPS.
